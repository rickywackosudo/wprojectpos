# Images for the studio page

Put the work images here, then add one entry per image to `../works.json`. See the main README for the fields.

- WebP preferred (quality ~85, about 100 KB each); JPG and PNG also work. Keep each file under ~300 KB.
- Lowercase file names without spaces, for example `avante-candy-fade.webp`.
- Keep the body near the middle of the frame: the colors on the image's edges are treated as background.
